# 01 · 架构概览

## 进程模型

```
┌─────────────────────────────────────────────────────────────┐
│  Main Process (Node)                                        │
│  ─ BrowserWindow 管理（主窗口 + N 个 popout 窗口）            │
│  ─ 文件系统 / 持久化 layout.json                             │
│  ─ IPC handler (ipcMain.handle)                             │
└────────────────────┬────────────────────────────────────────┘
                     │ contextBridge (preload, 白名单)
┌────────────────────▼────────────────────────────────────────┐
│  Renderer · 主窗口                                          │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ <App>                                                │  │
│  │   <DockviewReact />            ← 骨架                 │  │
│  │     ├── PanelHeader (含 Motion layoutId)             │  │
│  │     ├── PanelBody                                    │  │
│  │   <DecorLayer>                  ← 装饰，绝对定位     │  │
│  │     ├── <Spotlight /> (启动页)                       │  │
│  │     └── <BackgroundBeams /> (空状态)                 │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  Renderer · Popout 窗口（按需）                              │
│  ─ 复用同一份 PanelComponent 注册表                          │
│  ─ 通过 IPC 同步该面板的 props / state                       │
└─────────────────────────────────────────────────────────────┘
```

## 依赖方向

```
electron/main  ──→  electron/preload  ──→  src/shell  ──→  src/panels
                                            ↑
                                            └── src/lib
```

- `src/panels/*` 只依赖 `src/lib`，不知道 dock 是谁。
- `src/shell/dock/panels.ts` 充当反向控制：把面板注册到 Dockview 的 `components` map。
- `electron/preload` 只导出 `window.api.*` 三五个命名好的方法，**禁止**导出 `ipcRenderer` 原始对象。
