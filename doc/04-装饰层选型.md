# 04 · 装饰层选型

> 原则：**只挑两个组件，一个用于启动页，一个用于空状态。** 不在 dock 内部铺装饰背景，避免抢主线。

## 选定组件

| 组件 | 来源 | 用在哪里 | 替代理由 |
|---|---|---|---|
| **Spotlight** | Aceternity UI | 启动页（Splash / 欢迎页） | 鼠标聚焦感强，用户第一次打开时一秒抓住注意力 |
| **Background Beams** | Aceternity UI | 全部 panel 关闭时的空状态 | 视觉上提示"这里可以做事"，比纯灰色背景温柔得多 |

> 备选（不进 v1）：Magic UI 的 **Shimmer Button** 用在"恢复默认布局"按钮上、**Animated Gradient Text** 用在 logo。可在 v1.1 加。

## 不选谁

- ❌ **Globe / 3D Card** — 太重，CPU/GPU 占用高，且与 IDE 主题不合（炫但没意义）。
- ❌ **Background Boxes / Sparkles** — 持续动画，长时间使用会吃电池。
- ❌ **Meteors / Shooting Stars** — 注意力陷阱，会持续抢眼。

## 落点 ①：启动页 Spotlight

时机：app 启动到主窗口 ready，但 `layout.json` 还没读出来时（约 200~600ms 的过渡），盖一层 splash overlay；layout ready 后淡出。

```tsx
// src/shell/App.tsx 片段
{!layoutReady && (
  <div className="fixed inset-0 z-50 flex items-center justify-center bg-[#020617]">
    <Spotlight className="-top-40 left-0 md:left-60 md:-top-20" fill="white" />
    <h1 className="bg-gradient-to-b from-neutral-50 to-neutral-400 bg-clip-text text-5xl font-bold text-transparent">
      LayoutMotion
    </h1>
  </div>
)}
```

`Spotlight.tsx` 直接从 Aceternity 复制源码到 `src/shell/decor/Spotlight.tsx`，删掉无关 props，改名空间。

## 落点 ②：空状态 Background Beams

时机：当 `event.api.totalPanels === 0` 时（用户把所有 tab 都关了），在 dock 容器底层渲染一个 `BackgroundBeams` + 一个"恢复默认布局"按钮。

```tsx
// src/shell/dock/EmptyState.tsx
export function EmptyState({ onRestore }: { onRestore: () => void }) {
  return (
    <div className="relative h-full w-full overflow-hidden">
      <BackgroundBeams />
      <div className="relative z-10 flex h-full flex-col items-center justify-center gap-4">
        <p className="text-neutral-400">所有面板都关掉了。</p>
        <button
          onClick={onRestore}
          className="rounded-md border border-neutral-700 bg-neutral-900 px-4 py-2 text-sm text-neutral-100 hover:bg-neutral-800"
        >
          恢复默认布局
        </button>
      </div>
    </div>
  );
}
```

## 性能边界（硬约束）

- Spotlight / Beams 都用 SVG + CSS animation，**不**用 Canvas / WebGL。
- 启动页 splash 在 layout ready 后必须 unmount，不能只 `display: none`（SVG 仍会重绘）。
- 空状态出现后才挂载 `BackgroundBeams`，dock 有 panel 时立即 unmount。
- 全局观察 `prefers-reduced-motion: reduce`：开启时 Beams 改为静态渐变图（无 animation）。

## 复制还是安装

复制源码进仓库，理由：

1. Aceternity / Magic UI 官方文档里也是 copy-paste 工作流。
2. 自己拿到源码后可以删掉用不到的 props、合并 className 重复 utility，**少 60%+ 字节**。
3. 不被外部包版本绑定，升级 Tailwind / Motion 时不会被卡。

每个抄来的组件文件头部加一行注释：

```ts
// Source: https://ui.aceternity.com/components/spotlight (MIT)
// Modified: removed motion variants we don't use, renamed props.
```
