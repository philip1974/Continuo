# 06 · 里程碑与验收

> 5 个里程碑，每个里程碑有明确的 done 标准。所有打勾后才进入下一阶段。

---

## M1 · 工程骨架（预计 0.5 天）

**做什么**

- `pnpm create electron-vite` 初始化
- 接 React 19 + TypeScript + Tailwind v4
- 把 `electron/main`、`electron/preload`、`src/shell` 三个目录建好
- 配 ESLint + Prettier + tsconfig（strict）

**done 标准**

- [ ] `pnpm dev` 启动，主窗口出现一个 "Hello Continuo" 文本
- [ ] DevTools 里 `window.api` 是 `undefined` 之外的对象（preload 通了）
- [ ] `pnpm typecheck` 0 错误
- [ ] `pnpm build` 能产出 mac arm64 dmg / win nsis（暂可只做一种平台）

---

## M2 · Dockview 骨架接入（预计 1 天）

**做什么**

- 装 `dockview-react`
- 在 `DockShell.tsx` 渲染默认 4 面板布局（Explorer / Editor / Terminal / Output）
- 接 `layout:read` / `layout:write` IPC，刷新页面后布局保留
- 自定义 tab DOM（不加动画，先空壳）

**done 标准**

- [ ] 可以拖 tab 到任意位置成新 group
- [ ] 关闭一个 tab → 重启后仍是关闭状态
- [ ] 把 `layout.json` 删掉 → 自动落回 `defaultLayout`
- [ ] `app.getPath('userData')` 下能看到 `layout.json`，内容是合法 JSON
- [ ] 控制台 0 警告（特别注意 React key warning）

---

## M3 · Motion 动画接入（预计 1 天）

**做什么**

- 装 `motion`
- `SharedTab` 加 active indicator（落点 ①）
- `PanelMount` 加 AnimatePresence（落点 ②）
- 可选：`panel-title-${id}` 跨 group layoutId（落点 ③）
- 接 `MotionConfig reducedMotion="user"`

**done 标准**

- [ ] 切换 tab 时蓝色 indicator **平滑滑过**，不闪现
- [ ] 关闭 panel 时有淡出 + 微缩放，新 panel 进场有淡入 + 微上移
- [ ] 系统设置开"减少动效"后，所有动画立即变硬切
- [ ] 单帧 layoutId 节点数 ≤ 32（DevTools Performance 一帧采样验证）
- [ ] 拖动 tab 重排时不掉帧（连续拖 2s，FPS 不低于 55）

---

## M4 · 装饰层接入（预计 0.5 天）

**做什么**

- 复制 Aceternity Spotlight 源码到 `src/shell/decor/Spotlight.tsx`，删冗余 props
- 复制 Aceternity Background Beams 同样处理
- App 启动到 layout ready 之前显示 Splash + Spotlight
- 监听 `event.api.totalPanels === 0` → 渲染 EmptyState + Beams

**done 标准**

- [ ] 启动时能看到 Splash → Spotlight 高光跟鼠标
- [ ] layout ready 后 Splash unmount（用 React DevTools 验证）
- [ ] 关掉所有 panel → 出现 "所有面板都关掉了" 文案 + Beams + 恢复按钮
- [ ] 点恢复按钮 → 默认布局回来，Beams 立即 unmount
- [ ] `prefers-reduced-motion: reduce` 下 Beams 变静态（DevTools Rendering 面板可模拟）
- [ ] `LICENSE-3RD-PARTY.md` 已列出 Aceternity / Magic UI 引用

---

## M5 · Popout 真窗口（预计 1.5 天，可放 v2）

**做什么**

- 监听 Dockview 的 popout 触发
- 通过 `popout:open` IPC 起独立 BrowserWindow
- popout 窗口里渲染 `<PopoutHost panelId={...} />`
- 关闭 popout 窗口 → 通知主窗口（panel 重新挂回 dock 或丢弃）

**done 标准**

- [ ] 把 Editor tab 拖到屏幕外 → 弹出独立 BrowserWindow，标题、icon、preload 都是我们自己的
- [ ] 关闭独立窗口 → 主窗口收到通知，dock 状态正确
- [ ] popout 窗口刷新不崩溃
- [ ] 多开 3 个 popout 不抖动、不内存泄漏（连续开关 30 次，内存增长 < 50MB）

---

## 全流程验收 demo 脚本

打开 app → 看到 Spotlight 启动页 → 进入主界面 →
拖 Editor tab 到右侧分割 → 看到 indicator 滑过、panel 进场动画 →
关闭所有 tab → 看到 Beams 空状态 →
点恢复 → 默认布局回来 →
拖 Terminal tab 到屏幕外 → 看到独立窗口弹出 →
关闭独立窗口 → 主窗口正常。

整个 demo 不超过 90 秒，能演示就发布 v1。
