# i18n 国际化完整性与正确性审计(第十四 session 续,codex 协作,/goal 一次一个)

> 方向:用户看到错误语言文本 / raw key 泄漏 / 翻译缺失或错位。规则:本仓 macOS-only tested,只修能单测验证或纯逻辑/纯数据错误的项(i18n 基本都是),一次一个最高置信。

## 架构基线(预热)

- catalog 在 `electron/shared/i18n-locales/{en,zh,ko}.ts`,`en` 是类型源(`TranslationKey = keyof typeof en`)。
- **zh/ko 标注 `Record<TranslationKey, string>`** → TypeScript 强制 key 全集 + 禁多余 key。三者各 365 key 一致 → **catalog key 集漂移被类型系统封死**(typecheck 绿即无漏 key)。
- 占位符 `{xxx}` 跨 locale 一致(预扫 0 不匹配)。
- `translate(key: string)` 形参是 `string` 非 `TranslationKey` → **t() 引用不存在 key 不被编译期捕获**(露 raw key);**main 抛中文 message 经 IPC 到 renderer 直接展示**绕过 catalog —— 这两类是真矿脉。
