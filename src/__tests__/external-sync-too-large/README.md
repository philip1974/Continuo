# 外部重读时文件超过读取上限(external-sync-too-large)

行为契约:**打开的文件被外部写到超过编辑器的读取上限(64 MiB,如持续写入的日志)后,不再静默停在旧内容:提示一次
「已超过上限,已停止自动刷新」;文件变小(轮转 / 截断)后自动恢复刷新。**

## 行为

- 外部同步重读得到 `FS_FILE_TOO_LARGE` → warning 通知「「<文件名>」已超过编辑器可打开的上限(64.00MB),已停止自动刷新;文件变小后自动恢复」
  (三语)。同一文件只提示一次(通知按文件合并,`replaceKey`);tab 内容不动。其它读失败照旧不提示。
- 之后的文件事件照常尝试读取(超限的读取在读内容之前就按大小拒绝,开销很小);读成功 → 按磁盘内容刷新并清除记录,再次超限会再提示。
- 本次不提高读取上限(64 MiB 与写入上限一致:能打开的都能保存)。

## Modules

| File | Role |
|---|---|
| `src/panels/Editor/useExternalFileSync.ts` | 重读结果为 `FS_FILE_TOO_LARGE` 时提示 / 去重 / 恢复后清除 |

## Specs

| File | 覆盖 |
|---|---|
| `too-large-reload.spec.tsx` | 超限提示一次且按文件合并、内容不动;变小后恢复;再超限再提示;其它读失败不提示 |
