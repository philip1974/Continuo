# 列表行右键菜单:搜索结果 / 设置项 / 快捷键(对齐 VSCode)

搜索结果树、设置页的设置项、快捷键页的命令行右键弹出菜单(此前无反应)。外壳复用 tab 右键菜单的 `src/lib/TabContextMenu.tsx`
(Radix ContextMenu + design `MenuItem`,同 Explorer / 终端 / tab 菜单):

- 鼠标右键与 **Shift+F10 / 菜单键**(`src/lib/context-menu-key.ts`)都能打开;键盘打开时菜单定位在行处
  (`keyboardAnchor`:搜索树焦点在树容器上 → 活动行;设置项 → 行上的「更多操作」按钮;快捷键行 → 焦点所在的行内按钮)。
- **Esc** 关闭后焦点回到打开前的元素(行 / 行内控件 / 结果树);设置项与快捷键行可聚焦(`tabIndex=-1`,不进 Tab 序),
  右键按下即聚焦本行,Esc 后回到本行;回焦后行上画键盘焦点环(`focus-visible` 1px 内嵌 `outline-focus-ring`,与搜索结果树 /
  资源管理器行同一组类,鼠标点击不画;`--md-focus-ring` 对 surface 各级底色亮 / 暗 ≥ 3:1)。
- 菜单画在触发行所在文档:popout 子窗里的搜索面板 / 设置页,菜单画在子窗。
- 不适用的项置灰或隐藏(按 VSCode)。文案三语(en / zh / ko)。复制失败给 toast。

## 搜索结果(`search-context-menu.spec.tsx`,VSCode `MenuId.SearchContext`)

| 行 | 项(同组同序,`─` 为分隔) |
|---|---|
| 文件行 | 移除 / 从搜索中排除此文件类型 / 在搜索中包含此文件类型 ─ 复制 / 复制路径 / 全部复制 |
| 匹配行 | 移除 ─ 复制 / 全部复制 |
| 空白处(有结果) | 全部复制 |

- 右键的行成为活动行(VSCode 同);无结果时右键不弹菜单。结果树不支持多选,各项只作用于该行。
- 复制格式(VSCode `searchActionsCopy`):匹配 = `行,列: 预览`;文件 = 绝对路径 + 换行 + 各匹配(缩进 2 空格);全部 = 各文件以
  空行分隔;Windows 换行为 `\r\n`。复制路径 = 绝对路径。预览为结果行的预览文本(去行首空白、过长截断;VSCode 用整行)。
- 移除(Dismiss):文件行移除该文件全部结果;匹配行只移除该匹配,文件不剩匹配则一起移除;计数 / 状态行随之更新;活动行移到被移除行
  原位置上的下一行(没有则最后一行),焦点留在结果树。
- 排除 / 包含此文件类型(VSCode `modifySearchFileTypePattern`):`a.test.ts` → `*.test.ts`(无扩展名用文件名);追加到排除 / 包含框
  (已有其它 glob 以 `, ` 连接;已含同一 glob 不动),展开详情并立即重搜。
- 未做:替换 / 全部替换(本视图无替换)、文件夹行项(限制搜索到文件夹 / 排除文件夹 / 递归展开;结果不按文件夹分组)、在资源管理器
  视图中显示(资源管理器树无外部定位入口)。

## 快捷键页(`keybinding-context-menu.spec.tsx`,VSCode `keybindingsEditor` onContextMenu)

- 项:复制 / 复制命令 ID / 复制命令标题 ─ 更改快捷键…(未绑定时为「添加快捷键…」)─ 删除快捷键 / 重置快捷键 ─ 显示相同的快捷键。
- 复制 = `{ "key": …, "command": … }`(两空格缩进;key 为修饰键 + 主键小写,mac 上 ⌘ 写 `cmd`,未绑定为空串);命令标题为当前语言。
- 置灰:未绑定 → 删除 / 显示相同;未覆盖 → 重置;保留键命令(转到文件… / 显示所有命令)→ 更改 / 删除(不可改)。
- 更改 / 添加 → 打开录键弹窗(菜单先关闭、焦点回行内再打开,弹窗拿到初始焦点);删除 = 显式解绑(同录键弹窗清空);重置 = 回默认
  (同行内 ↺,焦点移到本行编辑按钮);显示相同 = 搜索框填入引号精确查询(如 `"ctrl+s"`),只列修饰键集合相同的命令。
- 未做:已绑定时的「添加快捷键…」(一个命令只存一条覆盖,不能再加一条)、更改 When 表达式(无 when 条件)。
