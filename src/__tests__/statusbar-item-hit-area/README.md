# 状态栏项的点击区域与悬停底色

此前状态栏的缩进 / 编码 / 行尾 / MCP 复制 / agent 撤销按钮只有文字那么大(约 15px 高),悬停只变文字颜色,难以点中。VSCode
`.statusbar-item`:每项占满状态栏高度(22px)、左右留白(`padding: 0 5px`),可点击项悬停有底色(`statusBarItem.hoverBackground`)。

1. **所有可点击项一致**(光标位置、缩进、编码、行尾、复制 MCP 配置、agent 撤销):占满栏高(24px)、左右 6px 留白、悬停底色
   `bg-hover`(语义 token)与前景 `text-fg`;键盘焦点环内嵌(组容器裁剪溢出,外扩的焦点环会被上下裁掉)。
2. **不可点击项**(工作区名、文件名、统计)同样左右留白、不加悬停底色;项间距由原来的 12px 间隔改为留白 + 2px 间隔,
   总宽度基本不变(窄宽时按原优先级隐藏,不出现溢出)。

## 规范

- `statusbar-hit-area.spec.tsx`:各可点击项的外框类(占满高度 / 留白 / 悬停底色)、不可点击项无悬停底色
- e2e `tests/e2e/statusbar-item-hit-area.spec.ts`:真实布局下可点击项高度 = 状态栏高度,悬停有背景色,点击上下边缘也能触发
