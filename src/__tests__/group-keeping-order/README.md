# groupKeepingOrder(按 key 分组的共享实现)

行为契约:**把列表按 key 分组;组的顺序是 key 首次出现的顺序,组内保持原顺序。**

设置搜索结果、设置分类页、快捷键页、Explorer 右键菜单的分组都走它(此前四处各手写一份)。

## 行为

- 空列表 → 空数组。
- 全部同 key(含单项)→ 一个组,`items` 就是入参数组本身(`owned=false`,不分配)。
- 多个 key → 每个 key 一组,组顺序 = 首次出现顺序,组内顺序不变;`items` 是新数组(`owned=true`,
  调用方可原地排序)。
- 不修改入参。

## 接线守卫

四个调用方的源码都引用 `groupKeepingOrder`,防止手写副本复活。
