# 待重启记录跨入口 / 跨页共享

全新安装的插件要等重启后的扫描才进插件列表。期间「已安装、待重启」记录由会话级模块 store
`src/plugins/pending-installs-store.ts`(id → 安装结果 name / version)统一维护,不持久化(重启后插件已进列表)。

此前设置页 Git 安装、市场卡片各用组件局部状态记,市场底部「从 Git URL 安装」完全不记;设置面板只挂载当前页,
切页即丢 → 卡片又给「安装」,点击 main 抛 EEXIST「已安装,卸载后再装」。市场 Git URL 段此前刻意不记,是因为当时
记录是页内局部状态、只服务卡片自身的乐观显示;统一 store 后它与其它入口装的是同一批插件,不记就会让卡片回到「安装」
触发同一 EEXIST,故一并纳入。

## 写入(三个入口)

- 设置页「从 Git 安装」、市场卡片安装 / 更新、市场底部「从 Git URL 安装」成功后都 `recordPendingInstall`
- id 已在插件列表(覆盖重装 / 更新)→ 不记(watcher 热重载即生效;列表不变、摘除不会跑,记了会在卸载后成幽灵)

## 读取(两个页面)

- 设置页:有记录且不在列表 → 待重启行(名称 / id / 版本 + 「需重启 Continuo 才能加载」提示 +「立即重启」按钮)
- 记录时同时发起热激活(`PluginManager.adoptInstalled`,见 `plugin-install-enable/`),落地即摘除
- 市场卡片:有记录且不在列表 → 「已安装（待重启）」disabled,不给「安装」

## 摘除

- 落地摘除集中在 store:记录时订阅 user plugin manager 列表变化,已进列表的 id 摘除(`pruneLandedPendingMap`),
  不依赖页面是否挂载
- 设置页卸载成功后同步清除该 id 的记录(兜住记录未被摘除的时序)

## 场景(spec)

- 设置页安装后切到别页再回来 → 仍显示待重启行
- 市场卡片安装后切页回来 → 卡片显示待重启,不再显示「安装」
- 市场底部 Git URL 安装市场里也有的插件 → 卡片显示待重启
- 设置页装的插件 → 市场卡片显示待重启;市场装的 → 设置页显示待重启行
- 落地后摘除(无页面挂载),随后卸载 → 两页都无幽灵
- 更新已在列表的插件不记 → 卸载后卡片回到「安装」
- 记录未被摘除时在设置页卸载 → 记录清除,无幽灵行
