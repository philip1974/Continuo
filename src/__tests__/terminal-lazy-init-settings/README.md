# 终端延迟初始化使用最新的设置与主题

行为契约:**终端面板以 0 尺寸挂载(dockview 的非激活页签)时,xterm 推迟到容器有尺寸才创建;
创建时使用的字号、光标样式、主题是「那一刻」的值,不是挂载时的值。**

## 背景

`useTerminal` 的创建 effect 只依赖 `termId`(改字号不能重建 term,否则丢历史输出),
字号 / 光标 / 主题由另外两个同步 effect 写到已存在的 term 上。但延迟初始化期间 term 还不存在,
同步 effect 直接返回且之后不会补跑;而创建函数闭包的是挂载时的值 → 用户在面板不可见时改了主题或
字号,激活面板后终端仍是旧主题、旧字号,直到下次再改设置。

## 行为

- 0 尺寸挂载 → 不创建 xterm。
- 等待期间字号 / 光标样式 / 主题发生变化 → 容器获得尺寸后创建的 xterm 用变化后的值。
- 有尺寸时直接挂载 → 用当前值(行为不变)。

## 不在本主题验证

- 已创建的 term 随设置同步(字号 / 主题 effect)→ 既有终端规范。
