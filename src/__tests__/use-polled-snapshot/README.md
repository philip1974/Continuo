# usePolledSnapshot(定时轮询外部快照)

行为契约:**对没有订阅接口的数据源定时读取;读到的值与当前值「相同」时保持原引用,不触发重渲。**

Marketplace 的已装插件 id 集合、设置页的第三方插件列表都走它(此前各手写一份 1s 轮询)。

## 行为

- 初始值 = 挂载时 `read()` 的结果;挂载后立即再读一次(数据源可能稍后才初始化完)。
- 每 `intervalMs`(默认 1000)读一次;`same(prev, next)` 为真 → 保持 `prev` 引用。
- 返回的 `refresh()` 立即读一次(同样经 `same` 去重),引用在组件生命周期内稳定。
- 卸载后停止轮询。
